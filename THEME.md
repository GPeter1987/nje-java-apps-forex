# Frontend theme

The web interface uses the free **Darkly** responsive theme from Bootswatch, based on Bootstrap 5. Bootswatch themes are released under the MIT License.

- Theme: Darkly
- Theme collection and source: https://bootswatch.com/
- License: MIT
- Application-specific layout and styling: `src/main/resources/static/css/app.css`

The theme stylesheet is loaded from jsDelivr, so an internet connection is needed to retrieve the shared theme. The MNB exchange-rate service also requires internet access.
